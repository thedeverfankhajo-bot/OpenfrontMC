# PocketMine-MP API 5 packaging

OpenFrontMC ships as a PocketMine plugin PHAR. Its ready-to-use world pack is
generated by booting the official PocketMine-MP 5 runtime, allowing the plugin
to create and render its managed worlds, and shutting the server down cleanly.

## Tools

- PHP 8.2 CLI with the `phar`, `yaml`, and `sqlite3` extensions
- Composer (for the project test and static-analysis scripts)
- `curl`, `tar`, `unzip`, and `zip`
- The official PocketMine-MP 5.x installer and its bundled PHP runtime
- The official PocketMine DevTools source, used to create the plugin PHAR

PocketMine-MP world folders use the Bedrock LevelDB storage format by default.
The repository intentionally downloads the runtime and build tools rather than
committing OS-specific executable binaries or a duplicate PocketMine server
installation.

## Build the plugin

From the repository root:

```sh
composer install
composer test
composer analyse
bash tools/build-phar.sh dist/OpenFrontMC.phar
```

The script stages only `plugin.yml`, `src/`, and `resources/` and invokes the
official DevTools `ConsoleScript.php`. It validates that the resulting PHAR
contains the manifest, main class, and default configuration.

## Install PocketMine-MP API 5

```sh
bash tools/install-pocketmine.sh .runtime/pocketmine
```

The installer selects the latest stable PocketMine-MP 5.x channel and installs
the matching PHP runtime into the requested directory.

## Generate the ready world pack

Use a clean, disposable PocketMine-MP directory. The server must not already
contain an OpenFrontMC world or plugin data directory.

```sh
bash tools/build-world-pack.sh .runtime/pocketmine dist
```

The builder copies `dist/OpenFrontMC.phar` into the server, starts PocketMine,
waits for the renderer completion message, and then stops the server cleanly.
It verifies both Bedrock LevelDB world folders and checks that all 256 default
territories are rendered in the matching SQLite database.

The output `dist/OpenFrontMC-WorldPack.zip` contains:

- `worlds/openfront_lobby/` (LevelDB)
- `worlds/openfront_world/` (LevelDB)
- `plugin_data/OpenFrontMC/` (matching SQLite map data and configuration)

The ZIP includes the SQLite metadata because the plugin uses it to track
territories and whether the physical map has already been rendered. Installing
only the world folders would cause a newly-created database to rebuild the map.

## Restore a world pack

First install PocketMine-MP and place the matching `OpenFrontMC.phar` in
`plugins/`. Then, while the server is stopped:

```sh
bash tools/install-world-pack.sh dist/OpenFrontMC-WorldPack.zip .runtime/pocketmine
```

The installer refuses to overwrite an existing OpenFrontMC world or data
directory. Back up live server files before replacing any world.

## GitHub Actions artifacts

The `Package API 5 plugin and world` workflow produces:

- `OpenFrontMC.phar` — installable PocketMine plugin
- `OpenFrontMC-WorldPack.zip` — pre-rendered LevelDB worlds plus matching plugin data
- `PocketMine-MP-API5-Linux-x86_64.tar.gz` — PocketMine-MP server PHAR, start script,
  bundled PHP runtime, plugin PHAR, and server properties for Linux x86_64

The PocketMine runtime archive is Linux x86_64 only. For Windows, macOS, or
other architectures, use the official installer on the target machine.
