# Player guide

- Use `/openfront help` to see available commands.
- Create a country with `/openfront country create <name> <TAG>`. Tags must be 2–4 uppercase letters or digits.
- Use `/openfront economy` to inspect resources.
- Use `/openfront join` to join or create a waiting match.
- Use `/openfront leave` to leave your current match.

Diplomacy, research progression, building placement, and complete territory claiming UI are not enabled in this MVP.
